### 発見したバグと修正

**問題**: ビルドしたバイナリが DB マイグレーションエラーで起動失敗

```
Failed to run the query 'INSERT INTO "__drizzle_migrations" ("hash", "created_at", "name", "applied_at") values(?, ?, , ?)'
```

**原因**: `packages/opencode/script/build.ts` の 54 行目で、マイグレーションデータに `name` フィールドが含まれていなかった。drizzle-orm 1.0.0-beta.16 では `name` が必須になったが、ビルドスクリプトは `{ sql, timestamp }` のみ返していた。

**修正**: `{ sql, timestamp }` → `{ sql, timestamp, name }` に変更（コミット `fd8ecf02a`）
