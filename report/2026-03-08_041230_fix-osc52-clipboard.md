# OSC52 クリップボード修正レポート

- 日時: 2026-03-08 04:12
- 作成者: Claude

## 前提条件・目的

- 目的: opencode の TUI からクリップボードへのコピーが機能しない問題を修正する
- 原因: `clipboard.ts` の `writeOsc52()` が `process.stdout.write()` で OSC52 エスケープシーケンスを直接書き込んでいるが、opentui の TUI レンダラーが 60fps で `process.stdout` にレンダリング出力を行っているため、OSC52 シーケンスがインターリーブして端末が正しく解釈できない
- 解決策: opentui の `renderer.copyToClipboardOSC52()` API を優先使用し、使えない場合のみ従来の `writeOsc52()` にフォールバック

## 作業内容

### 1. `clipboard.ts` — `OscCopier` インターフェースと renderer 経由 OSC52 送出

- `OscCopier` インターフェースを export（`copyToClipboardOSC52(text: string): boolean`）
- `Clipboard.copy()` にオプショナルな `renderer?: OscCopier` パラメータを追加
- renderer がある場合は `renderer.copyToClipboardOSC52()` を優先、失敗時のみ従来の `writeOsc52()` にフォールバック

### 2. `selection.ts` — Renderer 型に `OscCopier` を合成

- `Renderer` 型を `OscCopier &` で拡張
- `Clipboard.copy(text, renderer)` に renderer を渡すよう変更

### 3. `app.tsx` — `onCopySelection` コールバック

- `renderer.console.onCopySelection` 内の `Clipboard.copy(text)` → `Clipboard.copy(text, renderer)` に変更

### 4. `routes/session/index.tsx` — 3箇所の `Clipboard.copy()` 呼び出し

- share URL コピー（L366）: `Clipboard.copy(url, renderer)`
- メッセージコピー（L814）: `Clipboard.copy(text, renderer)`
- トランスクリプトコピー（L841）: `Clipboard.copy(transcript, renderer)`

## 検証方法

1. ワークツリー `.worktree/fix-osc52-clipboard` でビルド: `bun run build --single` → 成功
2. tmux 内で opencode を起動
3. `Ctrl+X` → `Y` でメッセージコピーを実行し、tmux のペーストバッファまたはホスト側クリップボードにコピーされることを確認
4. テキスト選択 → コピーの動作確認

## 結果・所見

- ビルド成功を確認
- `consoleOptions.onCopySelection`（L192）は render 関数の外で renderer 取得前に設定されるため変更不要。同等の機能は App コンポーネント内の `renderer.console.onCopySelection`（L249）で上書きされており、こちらに renderer を渡した
- ワークツリー: `.worktree/fix-osc52-clipboard`（ブランチ: `fix-osc52-clipboard`）
