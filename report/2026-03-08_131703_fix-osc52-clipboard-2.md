# OSC52 クリップボード修正レポート（第2回）

- 日時: 2026-03-08 13:17
- 作成者: Claude

## 前提条件・目的

- 目的: opencode の TUI 内でマウス選択によるクリップボードコピーを機能させる
- 環境: Alacritty → SSH → tmux → opencode (opentui/Zig TUI)
- 前提: 第1回修正で `renderer.copyToClipboardOSC52()` を優先使用するよう変更済みだが、依然としてコピー不可

## 参照レポート

- [第1回修正レポート](./2026-03-08_041230_fix-osc52-clipboard.md)

## 調査結果

### デバッグログによる発見

`copyToClipboardOSC52()` は `true` を返しており、opentui の Zig ネイティブ OSC52 送出は実行されていた。しかしクリップボードには反映されなかった。

### 根本原因

2つの問題が重なっていた:

1. **opentui の Zig は素の OSC52 (`\e]52;c;...\a`) を送出する**: tmux の `set-clipboard external` はこれを外部端末に転送するはずだが、実際にはこの環境では転送されなかった

2. **DCS passthrough ラップが必要**: `\ePtmux;\e\e]52;c;...\a\e\\` 形式（DCS passthrough）であれば tmux が外部端末に転送する。ただし tmux の `allow-passthrough on` 設定が必要

### 検証過程

| テスト | 方法 | 結果 |
|---|---|---|
| 素の OSC52 (シェル) | `printf '\e]52;c;%s\a' $(base64)` | 失敗 |
| DCS ラップ (シェル) | `printf '\ePtmux;\e\e]52;c;%s\a\e\\' "$b"` | 成功 |
| opentui native | `renderer.copyToClipboardOSC52()` → true | 失敗（素の OSC52） |

## 修正内容

### clipboard.ts の変更

1. `writeOsc52ViaRenderer()` 関数を追加:
   - opentui の `RenderLib.writeOut()` (Zig FFI) 経由で OSC52 を送出
   - tmux 検知時は DCS passthrough ラッピングを適用
   - Zig レンダラーと同一スレッドで実行されるため、stdout インターリーブが発生しない

2. `copy()` のフォールバックチェーンを変更:
   - tmux 内: `writeOsc52ViaRenderer()` → `copyToClipboardOSC52()` → `writeOsc52()` (stdout)
   - tmux 外: `copyToClipboardOSC52()` → `writeOsc52()` (stdout)

### tmux 設定

`~/.tmux.conf` に `set -g allow-passthrough on` を追加。DCS passthrough が tmux でブロックされないようにする。

### 変更ファイル

| ファイル | 変更内容 |
|---|---|
| `packages/opencode/src/cli/cmd/tui/util/clipboard.ts` | `writeOsc52ViaRenderer()` 追加、`copy()` フォールバック改善 |
| `packages/opencode/src/cli/cmd/tui/app.tsx` | renderer を `Clipboard.copy()` に渡す（第1回で変更済み） |
| `packages/opencode/src/cli/cmd/tui/routes/session/index.tsx` | renderer を `Clipboard.copy()` に渡す（第1回で変更済み） |
| `packages/opencode/src/cli/cmd/tui/util/selection.ts` | renderer を `Clipboard.copy()` に渡す（第1回で変更済み） |
| `~/.tmux.conf` | `set -g allow-passthrough on` 追加 |

## 結果・所見

- マウス選択によるクリップボードコピーが正常に動作することを確認
- tmux 環境での OSC52 は `set-clipboard external` だけでは不十分な場合があり、DCS passthrough + `allow-passthrough on` が必要
- opentui の Zig `copyToClipboardOSC52()` は素の OSC52 を送出するため、tmux 環境では機能しないケースがある
- `RenderLib.writeOut()` は TypeScript では private だが、ランタイムではアクセス可能で、Zig レンダラーと同一スレッドで安全に書き込める
