### 2. rails-upgrade リファレンスの改善

#### 改善箇所 1: 7.1-to-7.2.md チェックリスト（行 123-128）

ステップ 3（Gemfile 変更）と 4（Docker リビルド）の間に、`bundle update rails` による Gemfile.lock 更新ステップを追加:

```
[ ] 3. Gemfile 変更: gem "rails", "~> 7.2.0"
[ ] 3a. Docker 内で依存関係更新: ./docker_compose run --rm web bundle update rails
[ ]     → Gemfile.lock と vendor/cache が更新される
[ ] 4. Docker イメージ再ビルド: ./docker_compose build web
```

#### 改善箇所 2: 7.1-to-7.2.md の「Docker 環境での gem 更新手順」方法 2（行 28-34）

Gemfile.lock 更新ステップを明記:

```bash
# 方法2: イメージ再ビルド
# 1. ローカルで Gemfile を編集
# 2. Docker 内で Gemfile.lock を更新
./docker_compose run --rm web bundle update rails
# 3. Docker イメージを再ビルド（Gemfile.lock が変わったので必要）
./docker_compose build web
# 4. テスト実行
./docker_compose --profile test run --rm test rails test
```
