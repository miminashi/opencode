## 問題分析

### 1. plan_exit を自動で呼ばない問題
- LLM がテキストで「承認をお願いします」と書いたが plan_exit ツールを呼ばなかった
- 手動で「plan_exit を呼んでください」と指示が必要だった
- **対策**: plan モードのプロンプトに plan_exit 呼び出しを強調する必要あり（opencode 側の改善）

### 2. Ruby バージョン選択ミス
- 計画で Ruby 3.2.0 を選択（Rails 8.0 の最低要件）
- しかし Rails 8.1 は Ruby 3.3+ が必要
- Gemfile は `ruby "3.2.0"` に変更されたが、bundle update rails が Ruby 要件不一致で失敗した可能性
- **対策**: リファレンスの Ruby 要件をより目立つ位置に配置

### 3. Docker ビルド後にセッション終了
- 106K トークンに到達してセッションが終了
- テスト追加は完了したが、Rails アップグレードフェーズが未完了
- **対策**: コンテキスト管理の改善が必要。テスト追加とアップグレードをさらに分離する

### 4. モデルへのメソッド追加
- `processing?` と `failed?` メソッドをモデルに追加
- テスト対象メソッドが存在しなかったため追加。これは「テスト追加のためのプロダクションコード変更」に該当するが、メソッドの追加自体は合理的
