### 根本的なボトルネック

1. **コンテキスト限界（~100-120K tokens）**: Docker ビルドの長い出力がコンテキストを圧迫
   - テスト追加で ~30-40K、Rails アップグレード + Docker ビルドで ~60-80K
   - 合計で 100K を超えてセッション停止

2. **ローカル LLM の知識カットオフ**: Qwen3.5-35B が「Rails 8.1 は未リリース」と誤認
   - CLAUDE.md での明記で対処可能だが、LLM が読み飛ばす場合がある

3. **plan_exit 呼び出し**: ローカル LLM がツール呼び出しよりテキスト応答を好む傾向
   - プロンプトに明記することで改善されるが、100% ではない
