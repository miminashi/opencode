## 主要な知見

### 1. Bash タイムアウトが最重要パラメータ
2分→10分の変更が最大の効果。Truncation 回数: 149→12-34回に激減。Docker build が完了可能に。

### 2. Docker ビルドの鶏と卵問題
Ruby バージョン変更時に Gemfile.lock と Docker image の gem が不一致するループが最大のボトルネック。一時 Ruby コンテナ方式で解決。

### 3. Rolling Truncation は Docker 出力のコンテキスト圧迫を緩和するが副作用あり
- 介入指示の消失（iter 13: Ruby 3.3.0 指示が消える）
- Compaction 失敗（iter 18: "Session too large to compact"）

### 4. LLM の自律的判断の限界
- sprockets-rails 削除、Gemfile.lock 削除、boot.rb 変更、Rails ダウングレードなど、不適切な判断が多い
- CLAUDE.md で具体的に禁止する必要がある
