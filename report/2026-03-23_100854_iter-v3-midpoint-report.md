## 実施した改善

### Phase 0 (iter 23 開始前)
1. **bash.txt timeout テンプレート変数化**: LLM が timeout を 10分と認識するように修正
2. **CLAUDE.md v3 更新**: プロダクションコード変更緩和、timeout 禁止ルール追加
3. **Docker キャッシュウォーム**: 事前にアップグレード先 Docker イメージをビルド

### iter 23-30 で発見・対処した問題

| iter | 問題 | 対策 |
|------|------|------|
| 23 | `--no-cache` ループ (LLM サーバーダウン) | CLAUDE.md で `--no-cache` 禁止 |
| 24 | `docker rmi -f` でイメージ削除 + `--no-cache` ループ | Docker 絶対禁止セクション追加 |
| 25 | テスト未実行で完了宣言、Ruby 3.3.0 互換性問題 | テスト実行必須ルール追加 |
| 26 | bootsnap キャッシュ互換性エラー | bootsnap cache clear ステップ追加 |
| 27 | minitest 6.x 非互換、Rails ダウングレード | minitest pin、ダウングレード禁止強化 |
| 28 | RSpec 構文使用、巨大 edit で出力トークン超過 | Minitest stub 例示を追加 |
| 29 | skills ファイルの `--no-cache` 推奨が残存 | skills から `--no-cache` を完全除去、upgrade スクリプト作成 |
| 30 | LLM がスクリプト不使用、boot.rb 変更 | CLAUDE.md 手順をスクリプト呼び出しに簡略化 |

### 根本原因の発見 (iter 30 後の調査)

1. **`vendor/bundle/ruby/3.1.0`** がホスト側に残存 → bind mount で Docker コンテナに入り gem ロード失敗
2. **Rails 8.1.2 + Ruby 3.3.0 の非互換性**: actionview の anonymous rest parameter が Ruby 3.3.x で SyntaxError
3. **Ruby 3.4.1 が必要** であることを確認・修正

## 所見

### 成功要因
1. **upgrade スクリプト**: Docker build の複雑さを隠蔽し、LLM がテスト追加に集中できた
2. **Ruby 3.4.1 への切り替え**: Rails 8.1.2 との互換性問題を根本解決
3. **CLAUDE.md の累積改善**: 13 回のイテレーションで蓄積した知見が iter 31+ で結実

### 残存課題
1. **テスト追加数のばらつき** (8-23): プロンプトの「最低10個」要件が必ずしも守られない
2. **アンコメント違反** (iter 33): コメントアウトされたコントローラーアクションを復活させる傾向
3. **LLM サーバー応答速度**: iter 34 は Plan phase が異常に遅かった (270分)
4. **Compaction 後の自律性**: Compaction でプラン詳細を喪失し、テスト追加をスキップする傾向
