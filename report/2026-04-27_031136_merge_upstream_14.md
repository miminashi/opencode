### 4. ビルド失敗 → import パス修正

#### 失敗内容

`bun run build --single` が以下のエラーで失敗:

```
error: Could not resolve: "@/util/glob"
    at packages/opencode/src/session/compaction.ts:17
error: Could not resolve: "@/flag/flag"
    at packages/opencode/src/cli/cmd/tui/routes/session/question.tsx:19
```

その後、`@/filesystem` 系の追加エラーも発覚:

```
error: No matching export in "src/util/filesystem.ts" for import "Filesystem"
    at packages/opencode/src/tool/plan.ts:9
```

#### 原因

upstream PR #24309 で `packages/shared` が `@opencode-ai/core` にリネーム・統合され、`flag/flag.ts`・`util/glob.ts` 等が `packages/core/src/` 配下に移動した。

ローカルで追加されていた以下の import がこの変更に追従していなかった:

- `compaction.ts`: ローカル機能で `Glob.scan("*_STATE.json", ...)` と `Filesystem.readText(file)` を使用
- `question.tsx`: ローカル機能で `Flag.OPENCODE_EXPERIMENTAL_MARKDOWN` を使用
- `plan.ts`: `Filesystem` を使用

#### 修正

3 ファイルの import パスを upstream の規約に合わせて更新:

| ファイル | 修正前 | 修正後 |
|---|---|---|
| `packages/opencode/src/session/compaction.ts` | `import { Glob } from "@/util/glob"` | `import { Glob } from "@opencode-ai/core/util/glob"` |
| `packages/opencode/src/session/compaction.ts` | `import { Filesystem } from "@/util/filesystem"` | `import { Filesystem } from "@/util"` |
| `packages/opencode/src/cli/cmd/tui/routes/session/question.tsx` | `import { Flag } from "@/flag/flag"` | `import { Flag } from "@opencode-ai/core/flag/flag"` |
| `packages/opencode/src/tool/plan.ts` | `import { Filesystem } from "../util/filesystem"` | `import { Filesystem } from "../util"` |

`Filesystem` は `packages/opencode/src/util/index.ts` で `export * as Filesystem from "./filesystem"` の形で名前空間として再エクスポートされているため、`@/util` 経由でのインポートに変更した。

### LLM サーバ起動時の注意（CLAUDE.md 追記候補）

`start.sh` / `wait-ready.sh` の引数は **位置引数** で `[ctx-size|fit] [fit-ctx]` を取り、`--mode fit` のような flag 形式は受け付けない。今回 `--mode fit` で起動を試みて `--ctx-size` への値として `--mode` が渡され、llama-server がエラー終了した（"error while handling argument --ctx-size: stoi"）。

正しい呼び出し:

```
start.sh t120h-p100 unsloth/Qwen3.5-122B-A10B-GGUF:Q4_K_M fit 65536
wait-ready.sh t120h-p100 unsloth/Qwen3.5-122B-A10B-GGUF:Q4_K_M fit
```
