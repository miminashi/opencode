### Phase D の WARN について

`opencode run` サブコマンドの構文が upstream で `--prompt` フラグから positional `[message..]` に変更されただけでなく、修正後の正しい構文でも `UnknownError` (`err_8f4da744`) が返り、llama-server 側は task launch 後 8 秒で `should_stop condition` により abort されている。

- 仮説: `Refactor LLM route-first provider API (#28523)` / `Preview native LLM runtime stack (#27114)` 等の native LLM runtime 関連 refactor で、OpenAI-compatible (llama-server) 経路の CLI run handling に regression が入った可能性
- 影響範囲: 日常の TUI ワークフローは無影響（Phase A/B/C で確認済）。ベンチマーク・自動化スクリプトが影響を受ける可能性
- 次のアクション: 別 issue として `opencode run --print-logs --log-level DEBUG` で詳細取得、原因 commit を `git bisect` で特定

### Phase B-4 の WARN について

Option 4（Provide feedback）選択後にテキスト入力モードへの自動遷移が確認できず。マージ作業で `question.tsx` の import を統合した変更が影響している可能性は低い（imports 統合のみで logic 変更なし）が、`OPENCODE_BASE_MODE` mode 設定と upstream の dialog stack 廃止の組み合わせで focus 制御挙動が変化した可能性あり。緊急度 low（Option 1/2/3 経路は健全）。
