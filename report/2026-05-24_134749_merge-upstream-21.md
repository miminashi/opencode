## コンフリクトの有無と解消方法

**1 件のコンフリクトを解消**:

- ファイル: `packages/opencode/src/cli/cmd/tui/routes/session/question.tsx`
- 衝突箇所: import 文 + `useBindings` 内の `mode:` 指定
- 原因: upstream #28835 が `useOpencodeModeStack` + `QUESTION_MODE` 専用モードに移行する変更を入れたが、fork は `OPENCODE_BASE_MODE` を使う変更を独自に入れていた
- 解消方針:
  - import を統合: fork の `Match`, `Switch`, `useTerminalDimensions`, `ScrollBoxRenderable`, `Flag.OPENCODE_EXPERIMENTAL_MARKDOWN` を保持 + upstream の `onMount`, `onCleanup`, `useOpencodeModeStack` を追加
  - `OPENCODE_BASE_MODE` 削除（auto-merge 部分が `QUESTION_MODE` を採用済みで、`OPENCODE_BASE_MODE` は未使用化）
  - `const QUESTION_MODE = "question"` 定数定義を保持
- 他の auto-merge 対象（衝突なし）: bun.lock、agent.ts、tui/app.tsx、routes/session/index.tsx、permission/index.ts、provider/auth.ts、session/compaction.ts、session/llm.ts、session/prompt.ts、session/session.ts、sdk/js/src/v2/gen/types.gen.ts

解消後、マージコミット `39b7c5d92` を作成。
