### マージ後のビルド/型修正（コミット `256aed6e6`）

自動マージでは検出されない型崩れを typecheck で発見し修正:

1. **`agent.ts` plan permission の `task` キー重複**（TS1117）: upstream の `task: { general: "deny" }` と fork の `task: { "*": "deny", explore: "allow" }` が object literal に併存。fork の explore-only セキュリティ policy を採用し upstream 側を削除。
2. **`log` 未定義**（compaction/processor/prompt.ts、TS2304）: upstream #31310 で legacy `Log`（`@opencode-ai/core/util/log`）が削除されたため、fork コードの `log.*` 呼出を変換:
   - Effect generator 内（prompt.ts 5 箇所・processor.ts の stall 警告）→ `Effect.logInfo`/`Effect.logWarning`（stall 警告は setInterval 内から Effect コンテキストへ移動）
   - async/Promise 内（compaction.ts 2 箇所）→ `console.warn`
3. **`prompt.test.ts` の Reference/RepositoryCache**: モジュールが core へ移動し API も変化（`Reference.defaultLayer` 廃止）。ToolRegistry.layer がこれらを要求しないため、不要な `Layer.provide` 行と import を削除。

### clipboard（OSC52）の扱い

TUI standalone 化に伴い、fork の renderer 経由 OSC52（tmux DCS passthrough を Zig `writeOut` で送る interleave 回避策、旧 `clipboard.ts` の `writeOsc52ViaRenderer`/`OscCopier`）は **drop** し、upstream の `ClipboardService` context アーキテクチャを採用した。基本の **OSC52-over-SSH**（`packages/tui/src/clipboard.ts` の `writeOsc52`、tmux passthrough 込み）は保持されており、リグレッション Phase C-2 で dist バイナリに OSC52 シーケンス 11 件を確認済み。renderer 変種は regression フェーズ対象外の細部最適化で、新アーキテクチャへの移植は侵襲的なため見送り（必要なら別途 fork 拡張として再実装可能）。

#### CLI snapshot ドリフトの実体（マージ起因のユーザー可視挙動変更）

snapshot 再生成の diff は **`opencode run --thinking` フラグのデフォルトが `true` に変わった1行のみ**:

```
- --thinking   show thinking blocks                          [boolean]
+ --thinking   show thinking blocks          [boolean] [default: true]
```

upstream が thinking blocks（reasoning 表示）を**既定表示**に変更したもの。fork の reasoning streaming 機能（Phase D）とは方向性が整合する。fork 固有コマンドの help 破損は無し（spawn は `bun run src/index.ts` でマージ済みソースを直接実行）。本スナップショットは upstream の新 CLI surface を取り込む形で再生成しコミット済み。
