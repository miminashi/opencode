## 発見した問題とその修正

### ビルド時の依存解決 (2 回発生)

**現象**: worktree / main のいずれでも初回ビルドで新規依存 (`@opentui/solid/preload`, `solid-presence` 等) の resolve に失敗。

**原因**: `git worktree add` / `git merge --ff-only` 直後の `node_modules` に upstream 追加の依存が反映されていないため。

**対処**: 各 worktree で `bun install` を実行して lockfile を反映 → 再ビルドで成功。

**次回への申し送り**: merge-upstream の SKILL.md ステップ 4 は「必要なら」の但し書き付きで bun install に触れているが、上流の依存追加は頻繁に発生するので **worktree 作成直後の bun install は既定手順とする** のが安全 (m34 で 2 回発生、m33 でも同傾向)。
