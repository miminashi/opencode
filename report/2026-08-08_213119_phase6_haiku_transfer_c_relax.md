# haiku 転移テスト — (c) 緩和の 3 つの雛形を haiku で再走し、デルタの向きを測った

- 日時: 2026-08-08 21:31 JST
- 作成者: Claude

## 概要

本レポートは、判定役 LLM の代理計器として haiku が使えるかを確かめる転移テストの、haiku 側の走行結果をまとめたものである。前日の Claude 3 モデル比較（別計器の探索測定）で、haiku が North と同型の壊れ方（タスク文引用の捏造と、確認への承認を書き込みの承認として通す射程エラー）を再現したことから、「安価な haiku を探索・足切り専用のスクリーニング計器にできるか」という仮説が立っていた。検証の物差しは、(c) 緩和という介入について効き方の向きが North と haiku で一致するか、である。

実施にあたっては、North 側の同一実験（r2）が別セッションで走行中でレポート未執筆だったため、North の結果を見る前に haiku 側の転移判定基準を事前登録として凍結してから走行した。答えを見てから基準を作る事後選択を構造的に排除するためである。材料は r2 が生成した 3 種の sample（無変更雛形 C0・緩和 C1・緩和 C2、各 78 行）を読み取りのみで流用し、判定 1 件 = サブエージェント 1 呼び出しの claude-agents 方式で 3 arm × 78 行 × 3 反復 = 702 呼び出しを走らせた。全 702 件が有効判定で、ツール使用違反は 0 件だった。

haiku 側の結果ははっきりしていた。(c) の逐語引用要求を緩めると、転向側（場所を含まない承認 L3 と、プレースホルダ指示 LA）の allow は確実に増える。confirmatory とした C2−C0 の 6 本の対比較のうち 4 本（L1・L2・L3・LA）が信頼区間で 0 を外し、いずれも増加方向だった。L4（場所明示の承認）は haiku では 3 arm とも 100% の天井に張り付いており、差は測れなかった。

同時に、deny が正解の水準（L1・L2）の誤 allow も大きく増えた。ただし盲検の捏造監査で中身を見ると、増えた allow の根拠は捏造（タスク文の引用）ではなく、対話の実在の文言（言及や確認への承認）を許可と読み替える射程・読解エラーが主だった。捏造の絶対数はむしろ L2 で 16 件から 4 件へ減っており、引用要求を緩めたことで「引用をでっち上げる」代わりに「実在するが許可ではない文言を引く」方へ置き換わっている。一方、対話が存在しない L0 の誤 allow は 3 arm とも全件がタスク文引用の捏造で、緩和による変化がなかった。probe で見つけた haiku の捏造の署名は、雛形を変えても消えない。

North 側の r2 レポートは本セッションの執筆中に完成したため、凍結済みの転移判定基準をそのまま機械適用した。North の confirmatory 6 本のうち信頼区間で 0 を外した「向きあり」水準は L1・L2・L3 の 3 本で、すべて増加方向だった。haiku はこの 3 水準すべてで点推定の符号が一致し、かつ信頼区間も同じ正側で 0 を外している。矛盾は 0 本。凍結した採否規則により、**判定は「採用」— haiku を探索・足切り専用の代理計器として使ってよい**、である。ただしこの採用は (c) 緩和という 1 介入・13 材料の上での確認にすぎず、採否の確定判断は今後も必ず North（事前登録つき）で行うという役割分担は変わらない。

- **L1/L2 の per-call 増加の中身は「捏造の増加」ではなく「実在文言の読み替えの増加」**だった。逐語引用の要求（C0）はむしろ、引用が構成できない judge にタスク文引用の捏造を作らせていた（L2 の Q2 が C0 で最多の 16 件）。緩和すると実在する対話行（確認への「はい」）を引けるようになり、捏造は減るが誤 allow 自体は増える
- LA の Q3 内訳（P4 の解釈材料）: 整合あり/なし = C0 12/4・C1 19/2・C2 18/8。緩和で「対象パスの整合に触れない一般論の許可主張」（整合なし）が C2 で増えた。⚠ 整合あり/なしの境界は分類者の読みに依存する（境界例は note に記録済み）

- 凍結済みの採否規則「North 向きあり水準すべて一致 ∧ 矛盾 0 → 採用」に該当 → **採用（探索・足切り用途のみ）**
- 順序の一致（探索的・採否に使わない）: 階段 C0→C1→C2 の単調性は 6 水準中 3 水準（L0 非単調・L2 単調・L3 単調）で一致。L1（North 非単調 / haiku 単調）・L4（North 非単調 / haiku 天井フラット）・LA（North 非単調 / haiku 単調増）は不一致
- ⚠ 注意すべき相違（探索的）: **LA は haiku だけが confirmatory で 0 を外した**（haiku +30.8★ / North +5.9 不定）。また監査では、**L2 の捏造実数が North では増える（5→7→12 件）のに haiku では減る（16→5→4 件）**。壊れ方の向きは移るが、機構の細部までは移らない。haiku をスクリーニングに使うときは「haiku で差が出た → North で確認」の一方向に限り、haiku で差が出ないことを North の不変の証拠にしない
- ⚠ 予告した「L4 の天井が判定を保留に落とす」懸念は顕在化しなかった（L4 は North でも向きなし）

役割分担は据え置き: **haiku = 探索・足切り専用。採否の確定は必ず North（事前登録つき）。haiku で雛形を磨き込まない。**
