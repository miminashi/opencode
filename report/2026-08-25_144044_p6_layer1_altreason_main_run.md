# 判定役に代替先を書かせたら 4 割で正しく書けたが、示した先の 4 割弱は誤りだった

- 日時: 2026-08-25 14:40 JST
- 作成者: Claude

## 概要

第 2 層 DA-1 の本走で、**deny の理由に「どこへ書けばよいか」まで書くと、主モデルが正しい場所へ
書き直す率が 5.9% から 52.7% へ上がる**ことが確定した。ところが live の判定役 LLM（judge）は
その理由を作れていない（deny 138 件のうち代替パスの提示は 0 件）。理由を用意する道は 2 つある。
**機械が所在と規則と代替先を組み立てて付け足す案（M）**と、**雛形に「代替先を示せ」を足して
judge 自身に導出させる案（A1）**である。本ラウンドは後者を測った。

本レポートの結論は次のとおりである。**A1 は `R1`（所在も代替も正しい理由）を 0.0% から 43.0% へ
増やし、判定は「強い増加確定」となった。しかし同時に `R2`（誤った代替の提示）も 0.0% から 26.8% へ
増え、害の指標も「増えた」と判定された。** 事前登録 §5-8 の次アクション表はこの組み合わせに対して
**「⚠ 採らない。誤った代替は主モデルを誤った場所へ導く。M へ倒す」**と定めており、走行前に決めた
とおり **A1 は採用せず、機械で付け足す案（M）へ倒して第 3 層（実効阻止率 × タスク完遂率）へ進む**。

対比の中身はこうである。対照側（現行雛形）は有効判定 149 件のうち `R1` が **1 件も無い**。
deny と判定した 127 件のうち 108 件は `R3`（「その場所の外側だ」という境界の記述だけ）で、
走行前に予測した落ち先と一致した。介入側は deny した 126 件のうち **104 件で代替先を差し向け、
そのうち 64 件が正しく 40 件が誤り**だった。⚠ **登録済みの感度 1〜8 のすべてで判定は変わらなかった**
（最も保守的な感度 1 でも +34.9pt、悲観側の感度 8 でも +40.5pt）。

⚠ **利得も害も材料の型（kind）に大きく偏っている。** 正しく書けた 64 件の 56% は、
**期待代替先が worktree_root そのもの**である型（`bash_workdir_outside`）が占める。この型は
「worktree_root で実行せよ」と言えば当たる。一方**計画文書の移設先（`plan_doc_parent` 33 件）は
ひとつも当てられていない**（`R1` 0 件・`R2` 16 件）。⚠ **M はどの型でも構成上満点になる**ので、
この偏りは M へ倒す判断を補強する。

測定の成立検査は 1 つが不成立になった。**sham 対比（同一雛形・別 arm 名の C0s − C0）が G5 に抵触した** —
両 arm とも `R1` が 0 件だったためである。事前登録 §5-3 の「sham が計算できないときは δ_sup = 10pt」
条項が発動し、既定値で判定した。⚠ **その結果、呼び出し単位の揺れを sham から読む計画（限界 5）は
果たせていない。** ⚠ **δ_sup が clip 上限の 30pt だったら判定は「精度不足」に落ちていた**（実測の
CI 下限は +28.1pt で、25pt までなら増加確定になる）。一方、採点の再現性は高く、標本 60 件を 3 回
独立に再採点して**主指標に効く二値も畳んだラベルも 3 パスとも 100% 一致**した
（⚠ `held` だけは 91.7〜96.7% で、規準が予告したとおりラベルより再現しない）。

⚠ 本ラウンドの数値を live の値として読んではならない。対照 C0 は **live の雛形ではない**
（live は `structured` 87 / `structured_v3` 51）。⚠ **盲検も構造的に破れている** — A1 は代替先の
提示を求める雛形なので、理由の文体から arm が推定できる。⚠ **本設計では破れがどれだけ効いたかを
検出できない**（対照側の `R1` が 0 件なのは「現行雛形が代替先を書かない」という構造の帰結であって、
採点者が arm を当てたことの証拠ではない）。⚠ さらに期待代替先はパス規則の関数なので、**M は構成上
かならず満点になる**。本ラウンドで「LLM が規則に勝った／劣った」とは主張しない。
