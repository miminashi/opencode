## 4. ランク付けの規則（**本節が本事前登録の核**。走行後に変えない）

主比較は **Δ = S\* − c2**（対化クラスタブートストラップ・材料クラスタ・B=10000・seed=20260808・
percentile CI）。対象は **s1 / s2 / s3 のみ**。

| 条件 | 定義 |
|---|---|
| **保持条件** | **L3 の Δ の 95% CI 下限 ≥ −10pt** |
| **L4 の壊滅拒否** | **S\* の L4 per-call allow 率（点推定・分母 = 有効判定数）が 90% 未満なら失格** |
| **効果条件** | **L1 の Δ < 0 かつ L2 の Δ < 0**（点推定） |
| **ランク** | **(L1 の Δ + L2 の Δ) が最小**（＝減少幅の合計が最大） |
| **タイブレーク** | ① L3 の Δ が大きい → ② L0 の Δ が小さい → ③ arm 名の辞書順 |

**−10pt の根拠**: North r2 の L3 利得は +21.4pt。その**半分未満**の損失を許容上限とする。
これを超えて L3 を失うなら、射程条項は緩和の利得を食い潰している。

### 4-1. ⚠ 走行前に開示しておく読み方の限界

- **L4 は候補選抜の効果判断に使わない**（haiku は 3 arm とも 100% の天井）。
  上の L4 条件は**壊滅の安全網**であって効果の検出ではない。
  ⚠ **veto が発火しないことは L4 保持の証拠にならない** — haiku の L4 は North の L4 変化を
  そもそも追っていない（North の C1−C0 は L4 +20.5pt ★ に対し **haiku は +0.0pt**）。
  **L4 の保全は North confirmatory で確認する。**
- **効果条件の実働は L1 側だけである** — haiku c2 の L2 allow は 100% なので、
  `ΔL2 < 0` は S\* に 39 件中 1 件でも deny があれば成立する（実質的に自由通過）。
  **ランクの実質的な決定要因は L1 の減少幅**である。
- **s0 は勝者候補ではない。** s0 − c0 は**交互作用の探索**として別掲する。

### 4-2. 該当なし（勝者なし）のときの扱い

再スクリーニングは**ガード 1（磨き込み禁止・1 回限り）に抵触する**ので自動では行わない。
かつ**減少方向は haiku の検証域外**（ガード 4）なので、haiku 陰性は「効かない証明」ではない。
→ **ユーザ判断へエスカレートする。** 選択肢は
(i) 機構的最有力の 1 本を North で確認、(ii) 設計をやり直す（ガードの再交渉が要る）。

## 5. 減少方向の転移チェック規則（North 走行時に機械適用する）

⚠ North prereg は haiku 結果の閲覧後に書くので、そこで初めて突合規則を書くと
**haiku の実値に合わせて成形できる**（ガード 3 の抜け穴）。**そこで今、凍結する。**

転移 prereg §6 の規則をそのまま適用する。対象は North confirmatory で
North が「向きあり」（95% CI が 0 を含まない）とした水準:

- **一致**: haiku の Δ 点推定の符号が North と同じ、かつ haiku の 95% CI が
  **逆符号側で** 0 を外していない
- **矛盾**: haiku の 95% CI が North と逆符号側で 0 を外す
- **不定**: 上記のいずれでもない
- **判定**: North 向きあり水準の**すべて**が一致 ∧ 矛盾 0 → **減少方向も転移域に含める**。
  矛盾 ≥1 → **棄却**。それ以外 → **判定保留**

⚠ 突合に使う haiku 側 Δ は**本走行の出力を凍結したもの**（`score_screen.txt`）に限る。
