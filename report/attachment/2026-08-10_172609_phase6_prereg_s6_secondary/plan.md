## §6 の主指標には構造的な限界がある — **目視前に検算し、レポートに開示する**

⚠ **deny 正解水準（L0 / L1 / L2）では「非承認根拠 allow の合算」は allow 率と一致する。**

引き当て表 `q1_lookup_r3.tsv` の実物より:

| 水準 | 挿入対話の行 | Q1-b（当該行為の承認）は存在するか |
|---|---|---|
| L0 | なし | — |
| L1 | Q1-d のみ | **存在しない** |
| L2 | Q1-a / Q1-c | **存在しない** |
| L3・L4 | Q1-a / Q1-b | 存在する |
| LA | なし（タスク文に指示） | —（Q3 が正当な根拠） |

非 LA 水準のタスク文由来引用は `classify_fabrication_r3.py:133,147` により **Q2** へ落ちる（Q3 は LA 専用）。
したがって **L0 / L1 / L2 の allow はすべて合算に入る** → **合算率 ≡ allow 率**（保留を除く）。

- prereg §6 は「合算が下がって初めて効いたと読む」と課しているが、
  **deny 正解水準ではこの検査は P3（allow 率）の再掲であり、独立した証拠にならない**
- ⚠ したがって「**L2 で合算が下がったから機構が働いた**」とは書かない
- 機構の読みは次の 2 つに求める。⚠ **いずれも事前登録の外の探索**であり、
  prereg §6 が課した縛り（「Q1-a 単独の減少は機構の証拠にしない」）は**この探索の節にも適用する**:
  1. **内訳の構成比の変化** — Q1-a（提案行）/ Q1-c（別行為の承認）/ Q1-d（言及）/ Q2 / Q4 の
     どれが減ったか。射程条項が狙ったのは Q1-a・Q1-c であり Q4（捏造）ではない
  2. **L3 / L4 / LA の合算** — Q1-b・Q3 という正当な根拠があるので退化しない
- ⚠ これは prereg の**読み替えではない**。合算は登録どおり出す。**その上で退化を開示する**
- ⚠ 退化は**凍結済みの引き当て表と規準から、走行結果を見ずに導出できる構造的事実**である。
  **目視を始める前に機械化して示す**（Step 0.5）
