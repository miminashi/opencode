### 前ラウンドのデータを設計に使うことの扱い

材料が枯れているので hold-out は作れない。**避けるのではなく、用途を分けて開示する。**

| 用途 | 例 | r4 のデータを使ってよいか |
|---|---|---|
| 精度パラメータ（局外母数） | τ²・σ_w²・p_0・予測幅 | **使ってよい**。標本サイズ設計で分散を先行データから取るのは通常の手続き |

### undercoverage への対処（⚠ 非劣性では向きが逆）

13 クラスタの undercoverage は、帰無仮説検定では偽陽性を増やすが、**非劣性では CI が狭すぎる → 下限が高すぎる → 「保持確認」の偽陽性**を増やす。第 4 ラウンドの限界記述をそのまま流用できない。

- 主判定は alpha=0.05（凍結どおり）
- **感度線として alpha=0.01 の下限も走行前に登録して併記**（`paired_cluster_bootstrap(..., alpha=0.01)`。B/seed は触らないので凍結を破らない）。alpha=0.01 でも成立なら「強い保持確認」、0.05 のみなら「弱い保持確認」と語彙を走行前に決める
- ⚠ 「片側 5% にすれば通しやすい」は**逆方向の緩和**なので採らないと明記する（後から提案される経路を塞ぐ）

### `score_q1_delta_r5.py` の判定

```
M_PT = 20.0                      # ⚠ pt。走行前に凍結
0) 測定の成立検査（有効判定 0 / 材料欠損 / 両 arm の分子 0）→ 判定不能
   ⚠ 3 値化すると分子 0 は lo = hi = 0 ≥ −m で「保持確認」に化ける。
     成立検査を非劣性判定より**前**に置くことを selftest で固定する
1) lo ≥ −M_PT   → 保持確認
2) hi <  −M_PT  → 劣化確定
3) それ以外      → 精度不足で判定不能
```

合流:

| 保持の判定 | 次の扱い |
|---|---|
| 保持確認 | P-A2（`Q1-a` の減少）の評価へ進む |
| 劣化確定 | A の雛形は `Q1-b` を削る |
| **精度不足で判定不能** | **事前登録した次アクションを実行する**（⚠ ここを空欄にすると第 4 ラウンドと同じく判定が意思決定へ滑る） |

### selftest（⚠ ここが第 4 ラウンドの真因）

`score_q1_delta_r4.py` の C1〜C11 は **手書きの CI タプル**を `decide()` に渡していた。C1 の `_ci(-0.05, +0.08)` は幅 13pt で、**13 材料 × 3 反復では原理的に出ない値**である。「通るケース」はあったのに、その入力が実データで到達不能だったので達成不可能性を検出できなかった。

> **規則: 保持条件が通ることを示す selftest は、合成 CI ではなく、登録設計（M=13・R=5・併合水準・p_0）と同じ形の per-call 系列を凍結済み `paired_cluster_bootstrap` に通して得た CI で示す。**

必ず入れるケース:

- **A1 到達可能性**: `δ_m ≡ 0` の合成（⚠ **rep 間不一致率を r4 実測の 32% に合わせた現実的なノイズ入り版**が本命。決定的版だけでは CI が退化して不十分）で **`保持確認` が返る**ことを assert
- **A2 到達確率**: 乱数種を変えて N 回生成し、`保持確認` の割合が**登録した検出力（0.8）以上**であることを assert。⚠ 「1 回通った」で満足しない
- **A3 不足設計の検出**: **第 4 ラウンドの設計（R=3・L3 単独・m=10pt）**を合成で再現し、`保持確認` の割合が 0.2 未満になることを assert（**この selftest があれば第 4 ラウンドを止められた**ことを装置自身が示す回帰テスト）
- **B1 精度不足 ≠ 劣化確定**: Δ̂≈0 でノイズが大きい合成（r4 実データ相当）→ **`精度不足で判定不能`** であり `劣化確定` **でない**ことを assert
- **B2 劣化確定** / **B3 境界の等号**（lo がちょうど −m なら保持側）/ **B4 3 値の網羅性と排他性**
- **C 系の維持**: 単位取り違え（比率 `-0.154` を pt と混同）・`pt()` を通さない比較の静的検査・空虚な成立・対化・クラスタ単位・seed・分母は有効判定数（ask も入る）
- **D 併合固有**: D1 分母が単純結合（水準別率の平均でない）/ D2 同じ τ²/σ_w² で `W(L3 単独) > W(L3+L4)`。⚠ **τ² 支配の合成では縮まないケースも 1 本入れる**（「併合は万能ではない」を装置に覚えさせる）/ D3 目視範囲に L4 が無いのに併合指標を要求したら FATAL

合成生成器は `(M, R, 水準数, p_0, δ, τ)` を指定できれば足りる。⚠ **均質な合成だけにしない**（Δ が全複製で同じ値になり CI が退化して検出力を失う）。τ=0・中・大（σ_w≈0）の 3 点を必ず回す。

⚠ **装置の実装で登録文書の穴が見つかったら、本文を書き換えず末尾へ日付つきの追記を足す**（第 4 ラウンドの「追記 1」と同じ作法）。追記の冒頭に「走行前である」ことの証拠（`north_appr_r5_*` が不存在）を置く。

⚠ **装置 selftest が走行結果ゼロの状態で rc=0 になる証跡**を別名で保存する（`r4_device_selftest_*.txt` に倣う）。
