# DA-1 ⑤ 水準 (i) の採点の再現性を測る（GPU 不要）

## Context

DA-1 本走は主指標「deny 側 (a) 率の (i) − (iv)」で **+46.8pt・95%CI [+34.7, +58.5]・強い増加確定**を出した
（[レポート](/home/ubuntu/projects/opencode/report/2026-08-20_182704_p6_layer2_da1_main_run.md)）。
しかしこの分子である **(i) の (a) 127 件の採点の再現性は測っていない**。

- 事前登録 §8-6 の再現性検査は **パイロット（水準 (iv) と sham）だけ**で行われた。パイロットは (i) を走らせていないので、
  **分子の再現性は原理的に測れていない**（一致率 98.9% は (iv) についての値である）
- 本走の 4 採点群の間で **(i) の (a) 率が 42.9〜63.3%** とばらついた。⚠ 較正メモを受けた群が最高で、
  **メモの影響は分離できていない**（追記 8-2）
- ⚠ **採点者側の盲検は構造的に破れている**（生成内容から理由の有無が読める。追記 9 で開示済み）

→ ここが主指標に残る最大のリスクであり、次の実験（① live judge に (i) 相当の理由を作らせる／② 水準 (ii)）に進む前に固める。

⚠ **§8-6 は「パイロットのデータで行い、本走のデータでは行わない」と明示的に凍結している。**
本走の (i) を再採点するには**適用範囲を広げる事前登録の追記が先に要る**（宿題 E）。追記を書く前に再採点を始めない。

**ユーザ確認済みの設計**: 母集団は **(i) と (iv) の両方**／**各 40 件・計 80 件**を **3 回独立採点**／
採点者は **Opus 4.7 継承 × 3**（`model` を省略）。

## Step 5. 判定規則（⚠ Step 3 の採点より前に追記 10 へ凍結する）

**主要量 = 水準 (i) の「(a) か否か」の一致率（120 判定）**。

| 一致率 | 何をするか |
|---|---|
| **≥ 90%** | 再現性は十分と記録する。主指標の点推定・判定はそのまま |
| **80% 以上 90% 未満** | レポートに**採点者間の幅を併記する**（3 パスそれぞれで標本内 (i) の (a) 率を出し、最小〜最大を幅として記す）。判定は変えない |
| **< 80%** | 「**主指標の分子の採点は再現しない**」と記録する。⚠ 既存レポート冒頭への**訂正注記の追加をユーザへ提案する**（過去レポートは勝手に直さない）。次段 ① / ② の前に、不一致の内訳から規準の曖昧点を特定する作業を差し込む |

⚠ **どの結果でも確定ラベル 593 件は置き換えず、主指標の値・CI・判定を再計算しない。**
⚠ **一致率は再現性であって妥当性ではない。** 新しい採点者も同じ手がかり（内容から理由の有無が読める）を持つので、
**盲検の破れは一致率では検出できない**。この限界を結論に必ず書く。
