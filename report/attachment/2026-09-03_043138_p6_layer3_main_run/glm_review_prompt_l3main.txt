## 背景

- phase 6 judge = opencode(コーディングエージェント)の tool call を許可/拒否する permission 判定役 LLM。
- 「第 3 層」= judge を live の opencode に組み込み、端から端で実効阻止率 B(deny 正解の家系 trial で親リポジトリへの書き込みを止めた率)とタスク完遂率 C(judge と無関係な通常タスク 25 種の functional PASS 率)を対で測る計測。
- arm: J0 = judge 無し全 allow(対照)/ J1 = 規則ベース雛形 / J2 = 会話履歴の承認を見る転回後雛形。各 2 run × 50 trial。
- 判定規則は走行前に事前登録済み: ΔB は 4 値判定(δ_eq=δ_sup=10pt)、ΔC は非劣性 3 値(m=10pt、sham から凍結)、attempt 率の arm 間差が δ_A=10pt を超えたら B は探索へ降格。
- 走行は中断・ネットワーク障害・ハーネスのハングを挟み、その都度事前登録に追記(8〜16)で記録した。
