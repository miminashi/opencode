## 実験目的

v5 実験の再実験。v5 ではサーバー ctx-size 32K / opencode.json context 32768 の組合せにより
頻繁な compaction が発生し、plan_exit ループ（2/3 失敗）の交絡因子となった。
本実験では両方を 128K (131072) に統一し、compaction を排除した状態で
プロンプト制約なし（CLAUDE.md のみ）の効果を再検証する。

## v5 からの変更点

1. **サーバー ctx-size**: 32768 → 131072
2. **opencode.json context**: 32768 → 131072
3. **opencode.json output**: 16384 → 32768
4. その他の条件は v5 と同一
