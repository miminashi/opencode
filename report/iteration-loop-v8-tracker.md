## 実験目的

v7 実験（60% 達成率）の失敗 4 件は全て同一原因:
- CLAUDE.md が Ruby を 3.3.0 に厳密固定
- actionview 8.1.x が Ruby 3.3.0 と非互換（3.3.1+ で動作）
- LLM が Ruby アップグレード不可と判断し Rails 8.0 にダウングレード

v8 では Ruby バージョン固定を解除し、LLM が自律的に適切な Ruby バージョンを
選択できるようにすることで、成功率の向上を検証する。
副次的に、plan_exit プロンプト指示の削除がシステムプロンプトのみで十分かを確認する。

## v7 からの変更点

1. **CLAUDE.md**: Ruby バージョン要件セクション（13行）を削除
2. **CLAUDE.md**: Docker step 2 の `ruby:3.3.0-slim-bookworm` → `ruby:3.3-slim-bookworm`
3. **プロンプト**: step 3 に「必要に応じてRubyのバージョンをアップデートする」追加
4. **プロンプト**: `計画が完了したら plan_exit ツールを呼ぶこと。` を削除
5. その他の条件は v7 と同一（LLM、ctx-size、opencode build）
